# AskAnswer

AskAnswer — веб-приложение для вопросов и ответов, разработанное в рамках учебного курса по Web-технологиям.

Проект представляет собой read-only версию сервиса вопросов и ответов с использованием Django, PostgreSQL и Docker.

## Технологический стек

| Область | Технология |
|---|---|
| Backend | Python 3.13 |
| Web Framework | Django 6.1 |
| Database | PostgreSQL 16 |
| ORM | Django ORM |
| Frontend | HTML, CSS |
| Test Data | Faker |
| Debugging | Django Debug Toolbar |
| Containerization | Docker, Docker Compose |

## Основные возможности

- Просмотр новых вопросов.
- Просмотр популярных вопросов.
- Фильтрация вопросов по тегам.
- Просмотр отдельных вопросов и ответов.
- Пагинация вопросов и ответов.
- Отображение популярных тегов.
- Отображение лучших участников.
- Административная панель Django.
- Генерация тестовых данных с помощью Faker.
- Хранение данных в PostgreSQL.
- Запуск приложения через Docker Compose.

## Модели данных

В проекте используются следующие модели:

| Модель | Назначение |
|---|---|
| User | Пользователи Django |
| Profile | Профили пользователей |
| Question | Вопросы |
| Answer | Ответы |
| Tag | Теги |
| QuestionLike | Лайки вопросов |
| AnswerLike | Лайки ответов |

Для связей между моделями используются ForeignKey, OneToOneField и ManyToManyField.

## Запуск проекта через Docker

### 1. Требования

Перед запуском необходимо установить:

- Docker Desktop
- Docker Compose

### 2. Подготовка переменных окружения

Создайте локальный файл настроек Docker на основе примера:

```powershell
Copy-Item .env.docker.example .env.docker
```

При необходимости измените параметры подключения к базе данных.

### 3. Запуск приложения

Из корневой папки проекта выполните:

```powershell
docker compose --env-file .env.docker up --build -d
```

Docker Compose запустит два сервиса:

- web — Django-приложение;
- db — PostgreSQL.

При запуске Django автоматически применяются миграции базы данных.

### 4. Создание администратора

```powershell
docker compose exec web python manage.py createsuperuser
```

Следуйте инструкциям в терминале.

### 5. Доступ к приложению

Главная страница:

http://localhost:8000/

Административная панель:

http://localhost:8000/admin/

### 6. Проверка состояния контейнеров

```powershell
docker compose ps
```

Просмотр логов приложения:

```powershell
docker compose logs --tail=100 web
```

Проверка Django:

```powershell
docker compose exec web python manage.py check
```

## Генерация тестовых данных

Для автоматического заполнения базы данных реализована собственная Management Command:

```powershell
docker compose exec web python manage.py fill_db 100
```

Команда принимает параметр ratio, определяющий количество создаваемых записей.

Соотношение сущностей:

| Сущность | Количество |
|---|---:|
| Пользователи | ratio |
| Профили | ratio |
| Вопросы | ratio × 10 |
| Ответы | ratio × 100 |
| Теги | ratio |
| Лайки вопросов и ответов суммарно | ratio × 200 |

Для полного наполнения базы данных:

```powershell
docker compose exec web python manage.py fill_db 10000
```

При ratio = 10000 создаются:

- 10 000 пользователей;
- 10 000 профилей;
- 100 000 вопросов;
- 1 000 000 ответов;
- 10 000 тегов;
- 2 000 000 лайков.

Генерация выполняется пакетными операциями bulk_create для повышения производительности.

**Важно:** команду наполнения базы данных следует запускать один раз на пустой базе. Повторный запуск добавляет новые записи.

## Остановка приложения

```powershell
docker compose down
```

Данные PostgreSQL сохраняются в Docker volume.

Для полного удаления контейнеров и данных базы данных:

```powershell
docker compose down -v
```

Внимание: команда с параметром `-v` удаляет Docker volumes вместе с сохранёнными данными.

## Особенности проекта

Проект реализован как read-only версия сервиса. Просмотр и фильтрация данных доступны через пользовательский интерфейс, а управление записями осуществляется через Django Admin и команду заполнения базы данных.

Для удобства разработки предусмотрен Django Debug Toolbar, включаемый в режиме DEBUG.
## Запуск

Для просмотра сайта откройте файл `public/index.html` в браузере.
