# AskAnswer — Домашнее задание №4

AskAnswer — веб-приложение на Django, в котором пользователи могут задавать вопросы, публиковать ответы и взаимодействовать с другими участниками сообщества.

Данная версия расширяет функциональность домашнего задания №3: добавлены регистрация, авторизация, выход из аккаунта, редактирование профиля и формы для создания вопросов и ответов.

## Возможности

### Авторизация и регистрация
- Вход пользователей в систему.
- Регистрация с указанием логина, электронной почты, имени и пароля.
- Проверка надёжности пароля с помощью встроенных валидаторов Django.
- Автоматическое создание профиля при регистрации пользователя.
- Безопасная обработка параметра `next`, предотвращающая перенаправление на внешние сайты.
- Отображение состояния авторизации в шапке сайта.

### Профиль пользователя
- Просмотр и редактирование профиля.
- Изменение логина и электронной почты.
- Доступ к странице профиля только для авторизованных пользователей.
- Отображение аватара пользователя.

### Вопросы и ответы
- Создание вопросов с заголовком, текстом и тегами.
- Автоматическое создание новых тегов и использование уже существующих.
- Публикация ответов на странице вопроса.
- Перенаправление к опубликованному ответу с учётом пагинации.
- Проверка введённых данных и отображение ошибок.
- Сохранение введённых данных при возникновении ошибок валидации.

### Гостевой режим
- Защита представлений, требующих авторизации.
- Запрет на создание вопросов и ответов для неавторизованных пользователей.
- Отключение недоступных элементов интерфейса для гостей.
- Отображение подсказок для недоступных действий.

## Установка и запуск

### Требования

Перед запуском необходимо установить:

- Python 3.13 или новее
- Docker Desktop
- Docker Compose

### 1. Клонирование репозитория

```bash
git clone https://github.com/gremlin079/2026-VK-EDU-Web-12-Dmitriev-A.git
cd 2026-VK-EDU-Web-12-Dmitriev-A
```

### 2. Настройка переменных окружения

Создайте файл `.env.docker` на основе примера.

**PowerShell:**

```powershell
Copy-Item .env.docker.example .env.docker
```

При необходимости проверьте настройки подключения к базе данных.

### 3. Сборка и запуск приложения

```bash
docker compose up --build -d
```

### 4. Применение миграций

```bash
docker compose exec web python manage.py migrate
```

### 5. Создание администратора

```bash
docker compose exec web python manage.py createsuperuser
```

### 6. Открытие приложения

После запуска приложение будет доступно по следующим адресам:

- Главная страница: http://localhost:8000/
- Вход: http://localhost:8000/login/
- Регистрация: http://localhost:8000/signup/
- Профиль: http://localhost:8000/profile/
- Панель администратора: http://localhost:8000/admin/


```bash
docker compose exec web python manage.py test
```



Остановка приложения:

```bash

```
