# AskAnswer

Статический сайт вопросов и ответов, разработанный в рамках домашнего задания №1 по дисциплине Web-технологии.

## О проекте

AskAnswer — учебный Q&A-сервис, предназначенный для публикации вопросов и просмотра ответов пользователей.

## Страницы

- `index.html` — главная страница со списком вопросов.
- `question.html` — страница отдельного вопроса и ответов.
- `ask.html` — создание вопроса.
- `login.html` — авторизация.
- `signup.html` — регистрация.
- `profile.html` — профиль пользователя.
- `base.html` — общий HTML-каркас.

## Технологии

- HTML5
- CSS3
- Flexbox

## Структура проекта

Все HTML-страницы находятся в `public/`.

Статические ресурсы находятся в `public/static/`:
- `css/style.css` — стили сайта.
- `img/favicon.svg` — иконка сайта.

## Запуск

Для просмотра сайта откройте файл `public/index.html` в браузере.

Проект представляет собой статическую вёрстку без серверной логики и обработки форм.
