# AskAnswer

Учебный веб-сервис вопросов и ответов, разработанный в рамках домашних заданий №1 и №2 по дисциплине «Web-технологии».

## О проекте

AskAnswer — Q&A-сервис, предназначенный для публикации вопросов, просмотра ответов и взаимодействия пользователей.

Первая версия проекта представляет собой статическую HTML/CSS-вёрстку. Во второй работе проект переведён на Django с использованием представлений, маршрутизации и HTML-шаблонов.

## Функциональность

- Главная страница со списком новых вопросов.
- Страница популярных вопросов с сортировкой по количеству голосов.
- Фильтрация вопросов по тегам.
- Просмотр отдельного вопроса и ответов.
- Страница создания вопроса.
- Страницы входа и регистрации.
- Страница профиля пользователя.
- Пагинация списка вопросов.

Для демонстрации используются тестовые данные. Сохранение новых вопросов и полноценная авторизация пока не реализованы.

## Запуск локально

### 1. Создание виртуального окружения

```bash
python -m venv .venv
```

### 2. Активация виртуального окружения

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

### 3. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### 4. Применение миграций

```bash
python manage.py migrate
```

### 5. Запуск сервера

```bash
python manage.py runserver
```

После запуска сайт будет доступен по адресу:

http://127.0.0.1:8000/

## Запуск через Docker

Для сборки и запуска контейнеров выполни:

```bash
docker compose up --build
```

После запуска сайт будет доступен по адресу:

http://localhost:8000/

Для остановки контейнеров нажми `Ctrl + C`.

## Основные маршруты

| URL | Страница |
|---|---|
| `/` | Новые вопросы |
| `/hot/` | Популярные вопросы |
| `/tag/python/` | Вопросы по тегу |
| `/question/35/` | Страница вопроса |
| `/ask/` | Создание вопроса |
| `/login/` | Вход |
| `/signup/` | Регистрация |
| `/profile/` | Профиль пользователя |
